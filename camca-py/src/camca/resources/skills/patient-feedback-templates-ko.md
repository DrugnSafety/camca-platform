# 한국어 환자 피드백 템플릿

## 톤 원칙

GINA 2024 환자 커뮤니케이션 권고에 기반:

1. **격려 우선** — 잘한 점 먼저, 개선점 다음
2. **의학 용어 최소화** — "흡입" → "들이마시기", "actuation" → "통 누르기", "breath-hold" → "숨 참기"
3. **권유형 어조** — "~하세요" 대신 "~해 보시면 좋아요"
4. **한 번에 한 가지** — 여러 개선점을 동시에 지적하지 않음 (가장 중요한 1-2개에 집중)
5. **재시도 안내 포함** — 어떤 피드백이든 "다시 해 보실 수 있어요"로 마무리

## 연령군별 변형

| 연령군 | 톤 특징 | 글자 크기 권장 |
|---|---|---|
| 성인 (19-64) | 정중하고 친근 ("~하세요", "~좋아요") | 표준 |
| 노인 (65+) | 더 큰 글자, 짧은 문장, 단순한 단어 | 1.5배 |
| 소아 보호자 | 부모님 대상 ("자녀분께 ~해주세요") | 표준 |
| 청소년 (10-18) | 친근하지만 존중 ("~해 보면 어때요") | 표준 |

## pMDI 단계별 템플릿

### S1 — 흔들기

| 레벨 | 성인 | 노인 | 소아 보호자 |
|---|---|---|---|
| 3 | 흡입기를 잘 흔들어 약을 골고루 섞으셨어요. 👍 | 흔들기 잘 하셨습니다. | 자녀분이 잘 흔들었어요. 잘하셨어요. |
| 2 | 흔들기를 하셨지만, **4~5번** 정도 충분히 흔들어 주시면 약이 더 잘 섞여요. | 흔들기는 잘 하셨어요. 다음에는 4~5번 정도 더 흔들어 보세요. | 4~5번 정도 흔들도록 도와주세요. |
| 1 | 흔들기가 부족했어요. 다음에는 흡입기를 위아래로 **4~5번** 충분히 흔들어 주세요. | 흔들기를 좀 더 강하게 4~5번 해 보세요. | 흔들기가 약합니다. 자녀분 손을 함께 잡고 4~5번 흔들어 보세요. |
| 0 | 약을 섞지 않으면 흡입기 안의 약이 골고루 나오지 않아요. 사용 전에 **꼭 4~5번 흔들어** 주세요. | 약을 흔드는 것이 가장 먼저 해야 할 일입니다. 4~5번 위아래로 흔들어 주세요. | 흡입 전에 꼭 4~5번 흔들도록 안내해 주세요. |

### S3 — 숨 내쉬기 (흡입기 밖으로)

| 레벨 | 성인 |
|---|---|
| 3 | 흡입기를 입에서 멀리하고 숨을 잘 내쉬셨어요. |
| 2 | 숨을 내쉬셨지만, 흡입기를 옆으로 살짝 돌려서 내쉬면 더 좋아요. |
| 1 | 숨을 거의 안 내쉬고 들이마셨어요. 다음에는 **먼저 숨을 한 번 푹 내쉬고** 시작해 주세요. |
| 0 | 흡입기에 대고 숨을 내쉬면 약이 손상돼요. 흡입기를 **얼굴에서 멀리** 돌리고 숨을 내쉰 다음 사용해 주세요. |

### S5 — 들이마시기와 통 누르기 동시

| 레벨 | 성인 |
|---|---|
| 3 | 가장 어려운 단계인데 정말 잘 하셨어요! 들이마시기 시작과 동시에 통을 누르셨네요. 👏 |
| 2 | 거의 잘 하셨어요. 다음에는 들이마시기 시작과 통 누르기의 타이밍을 **조금 더 빨리** 맞춰 보세요. |
| 1 | 들이마시기와 통 누르기 타이밍이 어긋났어요. **숨을 들이마시기 시작하는 순간** 통을 함께 누르는 연습을 해 주세요. 거울 앞에서 연습하면 도움됩니다. |
| 0 (Critical) | ⚠️ **가장 중요한 부분입니다.** 통을 먼저 누른 다음 들이마시면 약이 입 안에만 머물러 폐에 거의 도달하지 못해요. **꼭 들이마시기 시작과 동시에** 통을 눌러 주세요. 다음 진료에서 함께 연습해 보겠습니다. |

| 0 | 약을 들이마신 직후 바로 숨을 내쉬면 약의 절반 정도가 다시 나와요. **꼭 10초 정도 숨을 참은** 다음 천천히 내쉬어 주세요. |

## Turbuhaler 단계별 템플릿 (핵심 단계)

### T2 — 통 돌리기 (찰칵 소리 확인)

| 레벨 | 성인 |
|---|---|
| 3 | 통을 잘 돌려서 **찰칵 소리**까지 확인하셨어요. 약이 제대로 준비됐습니다. |
| 2 | 통을 돌리셨고 소리도 났어요. 다음에는 통이 흔들리지 않게 똑바로 세운 상태로 돌려 주세요. |
| 1 | 통은 돌리셨지만 **찰칵 소리**가 들리지 않았어요. 소리가 날 때까지 한쪽으로 끝까지 돌렸다가 반대로 끝까지 돌려 주세요. |
| 0 (Critical) | ⚠️ 찰칵 소리가 나야 약이 준비됩니다. 소리가 나지 않으면 **약이 안 들어 있는 상태로 흡입**하는 것이에요. 통을 똑바로 세운 채로 끝까지 돌려 주세요. |

### T5 — 빠르고 깊게 들이마시기

| 레벨 | 성인 |
|---|---|
| 3 | **빠르고 깊게** 잘 들이마시셨어요. Turbuhaler에 딱 맞는 방법입니다. |
| 2 | 들이마시기를 잘 하셨지만, 시작부터 좀 더 세게 들이마시면 약이 더 잘 퍼져요. |
| 1 | 들이마시기가 약했어요. Turbuhaler는 pMDI와 달리 **빠르고 강하게** 빨아들여야 약이 분말 상태로 폐까지 들어가요. |
| 0 (Critical) | ⚠️ Turbuhaler는 **숨을 빨대로 빠는 것처럼** 강하게 들이마셔야 합니다. 천천히 들이마시면 약이 거의 안 들어가요. 평소 사용하던 흡입기(예: pMDI)와 다른 방법이 필요해요. |

## Critical Error 전용 알림 문구

Critical error 발견 시 일반 단계 피드백과 별도로, PDF 보고서 상단에 ⚠️ 표시와 함께 강조:

```
🔴 꼭 개선이 필요한 부분 (Critical)

[Critical error description from clinical-pharmacy-educator perspective]

→ 다음 진료 시 의료진과 함께 직접 연습해 보시기를 권장합니다.
```

예시:
```
🔴 꼭 개선이 필요한 부분 (Critical)

들이마시기 전에 통을 먼저 누르셨습니다.
이렇게 하면 약이 입 안에만 머물고 폐에는 거의 들어가지 못합니다.

→ 다음 진료 시 의료진과 함께 직접 연습해 보시기를 권장합니다.
```

## 종합 평가 (Verdict) 안내 문구

| 결과 | 환자 안내 |
|---|---|
| PROFICIENT | 흡입기 사용법을 잘 익히셨습니다. 현재 방법대로 계속 사용해 주세요. 1년에 1회 정도 재점검을 권장합니다. |
| ADEQUATE_WITH_EDUCATION | 흡입기 사용이 대체로 잘 되고 있습니다. 위에 안내드린 한두 가지 점만 개선하시면 더 좋아질 거예요. 다음 진료(약 1개월 후) 시 다시 한번 확인해 보겠습니다. |
| NEEDS_INTENSIVE_TRAINING | 흡입기 사용 방법을 좀 더 익히실 필요가 있습니다. 진료 시 의료진과 함께 단계별로 연습해 보시는 것을 권장합니다. **약효가 충분히 나오려면 정확한 방법이 중요해요.** |
| FAIL | 흡입기 사용 방법에 중요한 개선이 필요합니다. 약효가 충분히 나오지 못할 수 있어요. **다음 진료에서 의료진과 함께 처음부터 다시 확인하시기를 강력히 권장**합니다. |
